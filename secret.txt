Для запуска проекта нужно установить:

Node.js (LTS)
https://nodejs.org

Проверка:
node -v
npm -v

Git
https://git-scm.com
MongoDB Compass
https://www.mongodb.com/products/tools/compass
VS Code
https://code.visualstudio.com

После этого:

Клонировать проект:
git clone https://github.com/omurcomp/attendance-system.git

Frontend:
cd client
npm install
npm run dev

Backend:
cd server
npm install
npm run dev

Создать .env в папке server:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key

Основные npm пакеты:

Backend:
express
mongoose
cors
dotenv
bcryptjs
jsonwebtoken
nodemon

Frontend:
react-router-dom
axios
react-hot-toast
recharts
